# 单机版整包与专业版组件的版本边界

单机版以 standalone 整包交付，展示单机版发行版本，并按整包检查更新，不对内含的 Admin、Gateway 单独提示升级。
专业版的 Admin 与 Gateway 独立打包，分别展示各自的组件版本、检查更新，不增加额外的整套产品版本号。
不采用专业版统一总版本号，是因为它不能直接表达两个独立组件的实际安装组合；组件独立提示也能避免仅 Gateway 发布新版时，用户误以为 Admin 必须一并升级。

## Homebrew 升级提示的发布边界

单机版仅在目标版本的 Homebrew 安装源更新完成后提示“可升级”，仅创建 Release 不构成可升级条件。
这个边界与实际安装渠道保持一致，避免发布流程尚未完成时提示用户执行升级命令，却无法获得目标版本。

## 稳定版更新范围

本期仅将正式稳定版作为升级目标，排除 alpha、beta、rc 等预发布版本。
对于开发构建或无法识别的当前版本，显示“当前版本无法比较”，不判断为“可升级”或“已是最新版”。

## 多 Gateway 节点的版本展示

本期增加轻量的 Gateway 节点版本上报，按组件版本分组展示已上报节点的版本与数量，避免滚动升级期间用某个节点的版本代表全部节点。
未收到上报时显示“Gateway 版本未知”；版本分布仅反映已上报的信息。
本期不扩展为完整节点管理或自动升级系统。
